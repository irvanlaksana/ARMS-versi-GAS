Solusi Error: loadWorkspaceLogo_ is not defined

Error ini bukan dari file di repo ini (semua backend sudah digabung ke Code.gs). Error muncul di deployment Apps Script Anda karena masih ada:

  • File Workspace.gs atau Crm.gs lama di editor Apps Script Anda, atau
  • File HTML (js_main.html, js_workspace.html) versi lama di editor yang masih memanggil google.script.run.loadWorkspaceLogo_.

Langkah 1 — Diagnosa cepat

Buat file Script baru di editor Apps Script (klik + → Script), beri nama diagnose_workspace_logo, salin isi dari public/google-apps-script/diagnose_workspace_logo.gs di repo. Jalankan fungsi diagnoseWorkspaceLogo, lalu buka View > Logs.

Langkah 2 — Bersihkan file lama

Wajib: Hapus file Workspace.gs dan Crm.gs lama dari editor. Klik ikon ⋮ di sebelah nama file → Remove. Pada versi baru, isinya sudah digabung ke Code.gs; membiarkannya akan menimpa fungsi baru.

Langkah 3 — Samakan file HTML dengan repo

Buka setiap file HTML di editor dan bandingkan dengan yang ada di public/google-apps-script/ di repo. Daftar file yang harus sama persis:
  • Code (Code.gs)
  • Index
  • js_main
  • js_customer
  • js_crm
  • js_operations
  • js_letters
  • js_workspace
  • js_proposal
  • js_bulk
  • css_main
Cara tercepat: hapus semuanya, buat ulang dari awal dengan nama persis di atas, lalu salin isi dari repo.

Langkah 4 — Periksa appsscript.json

Klik Project Settings ⚙️ → centang Show "appsscript.json" manifest file in editor. Salin isi appsscript.json dari repo. Penting: klik Save 💾 (Ctrl+S) setelahnya.

Langkah 5 — Deploy versi baru

Deploy > Manage deployments > ✏️ Edit > Version: New version > Deploy. Versi baru wajib di-deploy, reload paksa (Ctrl+Shift+R) halaman web app, baru klik Coba lagi.

Langkah 6 — Verifikasi

Buka URL /exec, tekan F12 (DevTools) → tab Console. Tidak boleh ada error merah. Kalau masih ada loadWorkspaceLogo_ is not defined, berarti Langkah 2 atau 3 belum selesai: masih ada file lama di editor.

Masih error?

Beri tahu saya:

  1. Daftar lengkap file di sidebar kiri editor Apps Script Anda.
  2. Hasil log dari diagnoseWorkspaceLogo().
  3. Apakah Anda pernah paste-merge (menambah di bawah) Code.gs lama, atau benar-benar replace seluruh isinya?
