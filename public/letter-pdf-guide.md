# Surat Tugas & Kuasa

1. Pilih debitur dan kasus, lengkapi parameter, lalu klik **Simpan Penugasan**.
2. Klik **Buka Generator Surat** di samping tombol simpan. Situs `https://generator-surat-new.vercel.app/` dibuka dalam tab baru. Data ARMS tidak dikirim otomatis ke situs tersebut.
3. Buat dan simpan hasil surat dalam format PDF pada generator.
4. Kembali ke ARMS dan gunakan form **Upload PDF Surat Tugas / Kuasa** pada penugasan yang sesuai.
5. Pilih PDF maksimal 5 MB, periksa nama file, lalu klik **Upload PDF Surat**. Memilih file saja belum menyimpannya.
6. Gunakan **Unduh PDF** untuk mengambil dokumen tersimpan, atau pilih PDF pengganti dan konfirmasi melalui **Ganti PDF Surat**.

Penugasan wajib disimpan sebelum unggahan. Jika parameter penugasan sedang diedit, simpan perubahan dahulu. PDF lama baru diganti setelah unggahan baru berhasil; unduh salinannya bila masih diperlukan.

File pada mode demo disimpan di browser. File pada GAS berada di Google Drive terbatas dan hanya diakses oleh pengguna workspace yang terotorisasi. Cadangan JSON/CSV tidak memuat isi dokumen. Validasi PDF memeriksa format dasar, bukan keabsahan hukum atau pemindaian malware.
